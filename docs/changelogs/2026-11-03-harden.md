# ci: pin actions, optional PAT in lint workflows, ownership and license

Tracking: alva-ai/mono-meta#1115 (ggsrc org).

## Current state

- Ten Alva repositories call `golang-lint-v2.yml` or `golang-lint-v2_8.yml`
  at `@main`; three external repositories call `cruft-update.yml`.
- The lint workflows require `CICD_DOCKER_BUILD_PAT`. connectors calls
  `golang-lint-v2.yml` without it, so every connectors lint run has been a
  `startup_failure` since 2026-04-07.
- Actions are referenced by mutable tags (`@v4`, `@v7`, …).
- No CODEOWNERS, no LICENSE; README is one line.
- `golang-lint.yml`, `golang-test.yml` and `remove-old-artifacts.yml` have
  no callers found by code search.

## Changes (no breaking change for existing callers)

- Lint workflows: the PAT is optional; the `insteadOf` rewrite runs only
  when a token is passed; job token is `contents: read`; checkout does not
  persist credentials.
- Every action pinned by commit SHA within its current major version.
- Deprecation notes on the three workflows without callers (not deleted:
  an unknown caller would break).
- CODEOWNERS, Apache-2.0 LICENSE, README with usage and pinning advice,
  Dependabot for actions.

## Follow-up

- After merge, tag `v1` and ask callers to pin it (or its SHA).
- Alva callers (via alva-ai/mono-meta#1116): connectors works again without
  passing the secret; alfs and synthdb can drop it too if they have no
  private modules.

## Verification

- `actionlint` v1.7.7: no findings on all workflows.
